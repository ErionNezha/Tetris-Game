# 🟦 Tetris Game

Loja klasike Tetris e shkruar në Python me pygame — port i plotë dhe i luajtshëm në JavaScript/Canvas, me të njëjtat forma, ngjyra dhe sistem pikësh (lines²) si origjinali.

## 🚀 Si ta hapësh

Hap `index.html` në browser, kliko **Live Demo** dhe luaj: **← →** lëvizin, **↑** rrotullon, **↓** zbret ngadalë, **Hapësira** e lëshon menjëherë, **P** pauzë, **ESC** rinis.

## 📁 Struktura

```
Tetris-Game/
├── index.html
├── demo/  (Tetris i plotë në JS/Canvas)
├── original/Tetris.py  (origjinali pygame, i paprekur)
```
